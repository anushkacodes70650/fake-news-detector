## 🚀 About

> **Achieved 96.3% F1-score on FakeNewsNet benchmark with <200ms inference**

**Fake News Detector** is a production-ready **AI/ML** project built with **Python, BERT, Flask, Chrome Extension**.
Deployed on **Vercel + Render** with full CI/CD pipeline.

## 🚀 Quick Start

```bash
# 1. Clone
git clone https://github.com/anushkacodes70650/fake-news-detector.git
cd fake-news-detector

# 2. Install
pip install -r requirements.txt

# 3. Run
python main.py
```
